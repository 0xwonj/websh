# 404 response policy

This document is the signed response policy for a Websh route that cannot be
resolved against the mounted content filesystem.

The signature covers this policy document. It does not cover the requested
missing path, because that path is runtime data supplied by the browser URL at
the time the 404 page is rendered.

The runtime should preserve the browser URL, display the requested path in the
page details, and attach the signature footer for `/.site`.
